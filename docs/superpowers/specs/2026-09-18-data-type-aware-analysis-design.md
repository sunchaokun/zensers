# 2026-09-18-data-type-aware-analysis-design.md

## Context
Agent 分析质量在 R7-R9 稳定在 85 分，关键词评分系统到天花板。用户要求用 LLM 盲评验证真实质量，并通过数据类型感知策略进一步提升分析深度。

核心发现：不同研究类型（市场/政策/技术/投资/产业链）需要不同的分析策略，但当前 prompt 是通用的，没有根据数据类型自动适配。

## 设计
在 `deep_analysis.md` 中新增 "Data-Type-Aware Strategies" section，让 Agent 自动识别数据类型并应用对应策略。

### 六种数据类型 × 策略
1. 市场规模型：量化归因（量×价×结构）、口径一致性、时间序列区分
2. 竞争格局型：来源分级、交叉验证、份额归因
3. 政策法规型：原文引用、传导链、时间窗口
4. 技术趋势型：成熟度判断、路线对比、时间线
5. 投资分析型：时效性、风险量化、可比性
6. 产业链型：供需表、价格传导、库存周期

### 验证
- Round 10（smartphone）：验证市场规模策略
- Round pork4（pork）：验证产业链策略
- 对比 R9 基线
