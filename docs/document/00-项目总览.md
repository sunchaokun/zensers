## 1. 项目定位

**Zensers** 是一个 AI 驱动的自动化市场研究平台（Automated Market Research System），通过多 Agent 协作，完成从需求理解到专业报告生成的全流程研究任务。

核心理念：将传统需要数天的人工研究过程压缩至分钟级，同时实现知识的持续沉淀。

```
用户需求 → 多轮对话澄清 → 智能路由 → 多Agent并行执行 → 报告生成 → 知识沉淀
                                                                     ↓
                                                    下次研究：更智能、更快速（向上螺旋）
```

## 6. 关键架构决策

| 决策 | 选择 | 理由 |
|------|------|------|
| Agent 设计模式 | 固定 Agent + 动态 Agent | 核心能力稳定，特殊需求弹性扩展 |
| Master 不执行 | Orchestrator 只编排不处理 | 降低复杂度，职责清晰 |
| 研究框架驱动 | LLM 先生成框架再执行 | 保证报告内在逻辑一致性 |
| 两阶段研究 | 先数据采集，后深度分析 | 数据驱动分析，避免无数据空谈 |
| 约束优先 | Layer 0 做源验证/事实追踪 | 防止垃圾数据污染知识库 |
