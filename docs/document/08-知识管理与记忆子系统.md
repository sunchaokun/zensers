# 08 — 知识管理与记忆子系统

> 章节定位：理解系统如何存储、组织、检索和进化知识——从短期记忆到长期知识的完整链路。

---

## 1. 三层记忆架构

```
┌─────────────────────────────────────────────────────────────┐
│                    三层记忆架构                               │
│                                                             │
│  Layer 1: Core Memory (memory_core.json)                    │
│  ├── 用户偏好、核心需求、高频实体                           │
│  ├── 启动时加载 (< 10ms)                                    │
│  ├── 大小限制: < 10KB                                       │
│  └── 晋升条件: mention_count >= 5 或 recurrence_count >= 3  │
│                                                             │
│  Layer 2: Session Layer (sessions/)                         │
│  ├── sessions_index.json (会话索引)                          │
│  ├── sess_*.json (多会话文件)                                │
│  ├── 步骤级自动保存（变更即写）                              │
│  └── 启动恢复 (< 50ms)                                      │
│                                                             │
│  Layer 3: Full Data (knowledge_bank.db)                     │
│  ├── 所有实体、关系、数据点、洞察                            │
│  ├── 学习记录、功能请求                                     │
│  └── 按需查询                                               │
│                                                             │
│  Dream Mode (后台压缩服务)                                   │
│  ├── 6 阶段：定位 → 信号采集 → 整合 → 晋升 → 剪枝 → 归档   │
│  ├── 触发：会话结束 / 每24小时 / 手动 / 阈值                 │
│  └── 功能：压缩、去重、晋升、剪枝                            │
└─────────────────────────────────────────────────────────────┘
```

## 2. 知识生命周期

```
研究完成 → KnowledgeCompiler → 结构化知识条目
    │
    ├── 存入 UserKnowledgeBank (用户可检索)
    ├── 存入 CoreMemory (系统级知识)
    └── 记录到 WisdomStore (经验教训)
         │
         └── 下次研究时 → WisdomStore.get_recommended_skills()
                          → 为每个 aspect 推荐历史验证有效的技能组合

DreamMode (梦境模式)：
    └── 空闲时段 → 自动整理知识库
                  → 去重、关联、索引优化
                  → 方法论更新
```

## 5. 梦境模式详解

Dream Mode 是后台运行的**知识压缩与晋升服务**：

**6 阶段流程**：
1. **定位** (Positioning)：识别需要处理的知识
2. **信号采集** (Signal Collection)：收集相关信号
3. **整合** (Integration)：关联和合并
4. **晋升** (Promotion)：高频知识晋升到 CoreMemory
5. **剪枝** (Pruning)：移除冗余信息
6. **归档** (Archiving)：冷数据归档

**触发条件**：
- 会话结束时自动触发
- 每 24 小时间隔执行
- 手动触发
- 知识量达到阈值时触发

## 6. 智慧存储 (WisdomStore)

WisdomStore 记录历史研究的执行经验，用于优化未来路由决策：

- 记录每个 aspect 使用过的技能组合和执行效果
- 下次研究相同类型的 aspect 时自动推荐已验证有效的技能
- 持续优化：路由推荐随时间改进
