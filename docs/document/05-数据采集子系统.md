# 05 — 数据采集子系统

> 章节定位：理解系统如何从多种渠道获取数据——搜索引擎、网页抓取、PDF 解析、问卷调查。

---

## 1. 搜索引擎集成

系统集成了 6 个搜索后端，按优先级排列：

```
SearchSkill (多引擎搜索)
│
├── DuckDuckGo (DDGS 库) — 最先执行，零配置
├── Baidu SERP API — 优先级 1，中文搜索主力
├── Bing CN (web_fetch) — 优先级 2
├── Bing Intl (web_fetch) — 优先级 3
├── Google (Scrapling) — 优先级 10，降级用
└── Google HK (Scrapling) — 优先级 11，降级用
```

**搜索策略**：
- 优先级 1-3 的引擎同时发起请求，最快返回的优先使用
- 高优先级引擎失败时自动降级到低优先级
- 变体：NewsSearchSkill（新闻专用，DDGS news()）

## 2. 网页内容抓取

4 种抓取策略自适应选择：

```
WebScraperSkill
│
├── 策略1: 静态/反检测页面
│   Scrapling AsyncFetcher (anti-bot=True, adaptive=True)
│   适用：普通 HTML 页面及轻度反爬页面
│
├── 策略2: JS 渲染页面
│   Playwright (Headless Chromium)
│   适用：eastmoney.com, xueqiu.com, 36kr.com 等
│
├── 策略3: Jina Reader 回退
│   jina.ai 远程渲染服务
│   适用：Scrapling 和 Playwright 均失败的页面
│
└── 策略4: PDF 文档
    pdfplumber
    适用：研究报告、白皮书等 PDF 文件
```

自适应分类：URL → 判断内容类型 → 选择最优抓取策略。

## 3. 问卷子系统 (Survey)

系统内置完整的问卷调查能力：

```
Survey Subsystem
│
├── 问卷创建 → 模拟引擎 → 回答质量评估 → 数据分析
│
├── PersonaGen     — 人设生成器（模拟不同用户画像）
├── Simulation     — 模拟引擎（多角色并行回答）
├── Calibration    — 数据校准（WVS 基准数据）
│
└── 分析能力：
    ├── 情感分析 (Sentiment)
    ├── 交叉分析 (Crosstab)
    ├── 词云生成 (WordCloud)
    └── 统计分析 (Statistics)
```

## 4. 数据源权威度评分

系统为不同数据源分配权威度分数，用于数据加权和矛盾处理：

| 数据源 | 权威度 | 说明 |
|--------|--------|------|
| gov.cn | 0.95 | 政府官方数据 |
| mckinsey.com | 0.88 | 顶级咨询机构 |
| 学术期刊 | 0.85 | 同行评审 |
| 上市公司公告 | 0.90 | 法定披露 |
| 主流财经媒体 | 0.70 | 如东方财富、雪球 |
| 普通网站 | 0.50 | 博客、论坛等 |
| 非结构化数据 | 0.30 | 社交网络、评论 |

## 5. 技能注册体系

数据采集能力通过 SkillRegistry 统一管理：

```
SkillRegistry
├── 核心技能
│   ├── search_skill / web_search    # 多引擎搜索
│   ├── news_search                  # 新闻搜索
│   ├── file_skill                   # 文件操作
│   ├── http_skill                   # HTTP请求
│   ├── docx_skill                   # Word生成
│   ├── llm_skill                    # LLM调用
│   ├── web_scraper                  # 网页抓取
│   └── knowledge_query              # 知识库查询
│
├── LangChain 工具
│   ├── Tavily                       # 搜索API
│   ├── Arxiv                        # 学术论文
│   ├── Wikipedia                    # 百科知识
│   └── Python REPL                  # 代码执行
│
└── 专业分析技能（工厂注册，9 个）
    ├── MarketAnalysis / DataAnalysis
    ├── StockData / StockAnalysis
    ├── PolicyAnalysis / TechTrend
    ├── RiskAnalysis / AnnualReportParser
    └── XueqiuSkill
```
