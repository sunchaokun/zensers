# 07 — 报告生成子系统

> 章节定位：理解研究报告从原始数据到最终文档的完整生产流程。

---

## 1. 完整报告生成流程

```
Agent 执行完成
    │
    ▼
┌──────────────┐
│ ResultAggregator │ ── 聚合各 Agent 结果
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ ReportOrchestrator│ ── 报告升级整合
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│DocumentGeneration │ ── HTML 预览生成
│     Agent         │    使用 report_templates/ 模板
└──────┬───────────┘
       │
       ▼
┌──────────────┐
│QualityCheckAgent│ ── 质量评估 + 自动修复 (max 2)
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ PreviewRevision  │ ── 预览+修订工作流
│    Workflow       │    用户反馈 → 局部修订 → 重新预览
└──────┬───────────┘
       │
       ▼ 用户确认终稿
┌──────────────────┐
│ DocumentGeneration│ ── 正式文档导出
│     Agent         │    DOCX / PPTX / PDF
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ KnowledgeDeposit │ ── 研究成果存入知识库
└──────────────────┘
```

## 2. 报告模板体系

系统预置 12 种报告模板：

| 模板类型 | 用途 | 典型章节数 |
|---------|------|-----------|
| industry_report | 行业研究报告 | 8-12 |
| industry_weekly | 行业周报 | 4-6 |
| company_research | 企业研究报告 | 6-10 |
| quarterly_commentary | 季度点评 | 3-5 |
| annual_analysis | 年度分析 | 8-12 |
| conference_call | 电话会议纪要 | 3-4 |
| commercial_plan | 商业计划书 | 10-15 |
| pitch_deck | 路演PPT | 8-12 |
| investment_memo | 投资备忘录 | 6-8 |
| competitor_analysis | 竞品分析 | 5-8 |
| policy_brief | 政策简报 | 3-5 |
| market_brief | 市场简报 | 3-5 |

**模板定义示例** (YAML)：
```yaml
template:
  id: industry_report
  name: 行业研究报告
  sections:
    - id: market_overview
      title: 市场概览
      required: true
      data_priority: high
    - id: competitive_landscape
      title: 竞争格局
      required: true
      data_priority: high
  search_depth: deep
  analysis_depth: comprehensive
  quality_threshold: 0.8
```

## 3. 内容编排

ContentOrchestrator 负责将研究结果转换为 HTML 中间格式：

```
Research Results → ContentOrchestrator → HTML Intermediate Format
                                      ↓
                              ┌──────┴──────┐
                              ↓       ↓       ↓
                         Word     PPT     PDF
```

## 4. 格式转换

| 转换器 | 依赖库 | 说明 |
|--------|--------|------|
| HTML → Word | python-docx | 保留样式和排版 |
| HTML → PPT | python-pptx | 支持模板 |
| HTML → PDF | reportlab | 精确渲染 |

## 5. 预览修订工作流

用户可以在预览阶段对报告进行迭代修订（最多 10 轮）：

```
PreviewRevisionWorkflow
│
├── 初始预览生成 → HTML 推送到前端
│
├── 修订循环 (最多 10 轮)：
│   ├── 用户提交修订请求
│   │   ├── 整体反馈："加强竞争分析部分"
│   │   ├── 章节修订："修改第三章的数据"
│   │   ├── 新增章节："增加 ESG 分析"
│   │   └── 删除章节："移除附录"
│   │
│   ├── 意图分析 → RevisionIntentAnalysis
│   │   └── 理解修订意图，定位影响范围
│   │
│   ├── 修订传播 → AdjustmentCascade
│   │   └── 级联更新：修订一个章节影响其他章节
│   │
│   ├── 章节定位 → SectionLocator
│   │   └── 精确定位需要修改的内容位置
│   │
│   ├── 执行修订 → 调用 Agent 重新生成受影响章节
│   │
│   └── 重新预览 → 更新 HTML
│
└── 用户确认终稿 → 触发正式文档导出
```

## 7. 版本管理与导出

```
DocumentGenerationAgent
│
├── produce_document     # 完整文档生成
├── regenerate_document  # 重新生成
├── adjust_content       # 内容调整
├── export_document      # 导出到指定位置
├── list_versions        # 版本列表
└── rollback_version     # 版本回滚
```
