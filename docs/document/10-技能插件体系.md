# 10 — 技能插件体系

> 章节定位：理解系统的可插拔能力架构——自描述 SKILL.md + 自动发现引擎 + 目录式技能组织。

---

## 1. 架构概述

Skill 是系统的可插拔能力单元，位于七层架构的 Layer 4（能力层）。

**核心原则**：**SKILL.md（必需）+ Python 代码（可选）+ 自描述元数据**

新增一个 Skill 只需创建 1 个目录 + SKILL.md，系统通过自动发现引擎完成全链路注册。

```
SkillRegistry
│
├── 双轨注册：
│   ├── 传统注册: register_core_skills() / auto_discover_langchain_tools()  (旧技能)
│   └── 自动发现: init_from_discovery()  (目录式技能)
│
├── 技能来源：
│   ├── 内置技能: register_core_skills() 注册 9 个核心技能
│   ├── LangChain: 自动发现 (Tavily, Arxiv, Wikipedia, Python Repl)
│   ├── 目录式: SkillDiscovery 扫描含 SKILL.md 的子目录
│   └── 专业分析: 工厂注册 (Market, Stock, Policy 等 9 个)
│
├── 技能分类（自动构建）：
│   ├── SkillManifest.categories → CATEGORY_TO_SKILLS
│   ├── SkillManifest.priority  → SKILL_PRIORITY_MAP
│   ├── SkillManifest.keywords  → SKILL_KEYWORDS
│   ├── SkillManifest.aliases   → ALIAS_MAP
│   └── SkillManifest.aspect_coverage → ASPECT_SKILL_MAP
│
└── 技能热加载：watchdog 监控技能目录变更，自动重新加载
```

## 4. 自描述架构

### 4.1 SKILL.md 格式

每个目录式技能必须包含 SKILL.md，由 YAML front matter（元数据）+ Markdown（指令）组成：

```yaml
---
name: xueqiu
description: "雪球实时行情/热门股票/热帖/K线 (A股/港股/美股)"
version: "1.0"
categories:
  - financial-analysis
  - research
  - data-collection
priority: structured_db
keywords: [雪球, 行情, 港股, 美股, K线, 热门股]
aliases: [xueqiu_stock, stock_quote]
capabilities: [quote, kline, hot_stocks, search, search_and_quote, hot_posts, check]
data_types:
  zh: [股价, 估值, 换手率, 热门股, 实时行情]
data_source_keywords: [财务, 估值, 公司, 盈利, 营收, 市值, 港股, 美股]
action_rules:
  - pattern: "^(SH|SZ|BJ)?\\d{6}$"
    actions: [quote, kline]
  - pattern: ".*"
    actions: [search_and_quote]
action_param_map:
  quote: {symbol: symbol}
  kline: {symbol: symbol}
  search_and_quote: {query: symbol}
supports_topic_fallback: true
topic_fallback_pattern: "[\\u4e00-\\u9fff]+"
is_intrinsic: false
skill_type: standard
aspect_coverage:
  - Financial Analysis
  - Competitive Landscape
  - Industry Research
---
```

Markdown body 部分提供技能使用指令（When to use、Actions 表、Notes）。

### 4.2 自动发现引擎

`SkillDiscovery`（`src/skills/discovery.py`）是核心组件：

```python
class SkillDiscovery:
    def discover_all(self, skills_dir: Path) -> List[SkillManifest]
        # 扫描所有含 SKILL.md 的子目录
        # 解析 YAML front matter → SkillManifest

    def load_skill_class(self, manifest: SkillManifest) -> Optional[Type[Skill]]
        # 动态加载 skill.py 中的 Skill 子类
        # 无 skill.py → 返回 None（纯指令型用 InstructionSkill）

    def build_registries(self, manifests: List[SkillManifest]) -> SkillRegistries
        # 从所有 manifest 自动构建全链路注册数据
```

**SkillManifest** 包含 22 个字段（name, description, version, categories, priority, keywords, aliases, capabilities, data_types, data_source_keywords, action_rules, action_param_map, supports_topic_fallback, topic_fallback_pattern, is_intrinsic, aspect_coverage, skill_type, skill_dir, has_code, instructions）。

**SkillRegistries** 自动构建 8 个注册映射：
- `category_to_skills` — 替代手动 `CATEGORY_TO_SKILLS`
- `priority_map` — 替代手动 `SKILL_PRIORITY_MAP`
- `keywords_map` — 替代手动 `SKILL_KEYWORDS`
- `alias_map` — 替代手动 `_SKILL_ALIAS_MAP`
- `capabilities_map` — 能力→技能映射
- `data_source_skill_map` — 替代手动 `DATA_SOURCE_SKILL_MAP`
- `structured_data_capabilities` — 结构化数据能力
- `aspect_skill_map` — 替代手动 `ASPECT_SKILL_MAP`

### 4.3 注册集成

`SkillRegistry.init_from_discovery()` 在 orchestrator 初始化时调用：

```python
# src/core/orchestrator/orchestrator.py
skill_registry.init_from_discovery(Path("src/skills"))
```

流程：`discover_all()` → 逐个 `register_manifest()` → 有代码的 `load_skill_class()` + `register_factory()` → 无代码的用 `InstructionSkill(manifest)` → `_validate_manifests()` 校验。
