## 3. 重要方案详述

### 3.1 EntityResolver（P0, 待编码）

**状态**：✅ 完整设计文档 `2026-06-26-entity-resolver-skill-routing-design.md`
**目标**：在 Task Decomposition 阶段前置一个实体解析层，提升意图分析精度

```
用户输入 → EntityResolver → 解析后的结构化任务
  │          ├── 实体识别（公司、行业、产品）
  │          ├── 实体消歧（模糊匹配 → 精确匹配）
  │          └── 实体→Aspect 路由
  │
  ▼
Orchestrator → Decomposition → Agent → ...
```

**关键特性**：
- 实体链接：模糊字符串 → 精确股票代码/公司 ID
- 映射 Redis：`company_name → {stock_code, industry, aliases, skills}`
- Aspect 生成：实体属性 → Zensers Aspect（基于 `config/research_frameworks.yaml`）

**现状**：未开始编码。Skill 自描述架构已完成（SkillDiscovery + init_from_discovery），前置依赖已解除。

### 3.2 FinancialForecastAgent（P1, 待编码）

**状态**：✅ 完整设计文档
**目标**：独立 Agent 系统，可针对上市公司进行财务预测分析

**核心功能**：
- 财务数据采集（从 Xueqiu / Akshare 获取）
- 财务建模（收入预测、利润预测、现金流分析）
- 报告生成（专门的财务分析报告模板）

**位置**：独立模块 `analysis/financial_forecast/`
**依赖**：
- Xueqiu Skill V2（数据源）
- 报告生成器（报告调用链路）

### 3.3 多层分析框架（P1, 待编码）

**状态**：✅ 完整设计文档
**目标**：为报告提供分层分析能力——从不同粒度审视同一研究对象

**设计要点**：
- 宏观层：行业整体概览（行业周期、政策环境）
- 中观层：细分市场/特定主题（如新能源的不同技术路线）
- 微观层：特定公司/产品分析

**集成方式**：在 Agent Decomposition 阶段，Preprocessor 自动判断是否需要多层分析。

### 3.4 Forensics Analysis 法证分析模式（P1, 待编码）

**状态**：✅ 完整设计文档 `2026-07-02-forensic-analysis-mode-design.md`
**目标**：提供类似司法鉴定级别的报告质量审查能力

**核心特性**：
- 逐句检视：每个事实断言都要标注来源和置信度
- 逻辑链追踪：可视化论证结构
- 矛盾检测：跨章节交叉引用一致性

**设计亮点：动态证据链构建**
```
ForensicReport = {
    claims: List[Claim],          # 所有事实断言
    evidence_chain: Graph,        # 证据链 DAG
    contradictions: List[Conflict],# 检测到的矛盾
    confidence_map: Dict[str, float],  # 置信度映射
    recommendations: List[str]    # 修复建议
}
```

### 3.5 Xueqiu 雪球集成 V2（P1, ✅ 已完成）

**状态**：✅ 完整设计 + 完整实现
**目标**：升级雪球集成为标准 Skill（自描述架构的首个迁移技能）

**特性**：
- 实时行情查询（A股/港股/美股）
- 热门股票列表
- 热门帖子获取
- K 线数据下载
- 搜索并获取报价（search_and_quote）

**已实现**：
- `src/skills/xueqiu/SKILL.md` — 自描述元数据（22 个字段 + 指令）
- `src/skills/xueqiu/skill.py` — XueqiuSkill 完整实现
- 通过 `init_from_discovery()` 自动注册到 SkillRegistry
- 未登录时自动通过 Screener 公共 API 降级
