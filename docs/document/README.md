## 阅读路径

| 角色 | 建议阅读顺序 |
|------|-------------|
| **新加入者** | 00 → 01 → 02 → 03 → 04 → 12（快速建立全景认知） |
| **架构师** | 00 → 01 → 04 → 10 → 11 → 13 → 14 → 15 → 16 → 90（关注架构决策与竞争定位） |
| **后端开发者** | 02~09（按负责模块阅读）+ 10 + 12 + 15 + 16 |
| **前端开发者** | 01（API/通信设计）+ 12（前端架构）+ 07（预览修订）+ 15（SSE 事件） |
| **运维/部署** | 12（配置与存储）+ 11（MCP）+ 14（版本） |

## 原始文档溯源
